# Portafolio — Brayan Manuel García Guibert

Portafolio personal desarrollado con React, Vite y Tailwind CSS.

🔗 **En vivo:** https://bryangarcia.vercel.app

## Stack

- React 18
- Vite
- Tailwind CSS 3

## Desarrollo local

```bash
npm install
npm run dev
```

Abre http://localhost:5173

## Build

```bash
npm run build
npm run preview
```
